# 🐬 Dolphin AI - Cybersecurity Educational Assistant

A powerful AI-powered cybersecurity educational tool built with CustomTkinter and Groq API.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## ✨ Features

- 🤖 **AI-Powered Chat** - Powered by Llama 3.3 70B via Groq API
- 🎨 **Multiple Themes** - Cyberpunk, Matrix, Nord, Dracula, and more
- 💾 **Chat History** - Save and load your conversations
- ⭐ **Favorites** - Mark important messages for quick access
- 📤 **Export** - Export chats to HTML, Markdown, or JSON
- 🔤 **Adjustable Font Size** - Customize your reading experience
- 🔄 **Multiple Models** - Switch between different AI models

## 📋 Requirements

- Python 3.8 or higher
- Groq API Key (free at [console.groq.com](https://console.groq.com))

## 🚀 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/dolphin-ai.git
   cd dolphin-ai
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python cyberhelper.py
   ```

4. **Enter your Groq API key** when prompted on first launch.

## 🔑 Getting a Groq API Key

1. Visit [console.groq.com](https://console.groq.com)
2. Create a free account
3. Navigate to API Keys section
4. Generate a new API key
5. Copy and paste it into the application

## 📁 Data Storage

Your data is stored locally at:
- **Windows:** `C:\Users\<username>\.dolphin_ai\`
- **Linux/Mac:** `~/.dolphin_ai/`

This includes:
- `settings.json` - Your API key and preferences
- `chats/` - Saved chat histories
- `favorites.json` - Your favorited messages
